# Contributing(参与贡献)

Thanks for helping improve the learning loop(学习闭环). The project is intentionally narrow: one synthetic note leads to open recall, transparent feedback, and an adaptive review date.

## Before opening a pull request(拉取请求)

1. Open an issue for any feature that adds a server, account, model provider, editor, sync layer, or new runtime dependency(运行时依赖).
2. Use only invented sample content. Do not include real notes, transcripts, identities, credentials, employer material, private endpoints, or copied product assets.
3. Keep typing as a complete fallback for every voice interaction.
4. Preserve semantic HTML(语义化 HTML), visible keyboard focus, and reduced-motion behavior.
5. Run the complete check before submitting:

```bash
npm install
npm run check
```

## Good first contributions(适合首次贡献)

- improve a synthetic rubric without making it opaque;
- add a test for a real scoring or scheduling edge case;
- improve keyboard, screen-reader, or browser compatibility;
- clarify privacy, limitations, or learning-science explanations.
